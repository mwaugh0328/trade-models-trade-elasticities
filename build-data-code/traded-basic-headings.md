# Traded Basic Heading Categories

ICP basic heading categories selected as tradable goods in the price gap data construction pipeline. Source: `build-data-code/2017-price-gap/2017_catagories_traded.csv`, rows where `Traded == 1`. Processing: `ICP_micro_price_data_PPP.ipynb` → `2017_traded_prices.csv`.

The 2004 (62 categories) and 2011 (71 categories) samples are similar in composition — the same broad COICOP-based groups are represented — but differ due to structural changes in ICP basic heading definitions across rounds.
